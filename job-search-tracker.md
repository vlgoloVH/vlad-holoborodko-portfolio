## Стоп-сигнали (пропускати одразу)

| Сигнал у тексті | Що означає |
|---|---|
| `401(k)`, `must reside in US`, `hiring in these states` | США only — з Києва ні |
| `Secret clearance`, `visa sponsorship not available` | США громадянство |
| `based in [Portugal/Netherlands/Berlin/London]` | прив'язка до країни, релокація |
| `5+ years native iOS/Android` | вузький мобільний спец — не твоє |
| `conversion-obsessed`, `ARR`, `paywall`, `funnel` | growth-дизайн — не твоє |
| `Shopify Plus`, `DTC ecommerce` | ecommerce спец — не твоє |
| `Russian C1` | російськомовна команда |

**Зелене світло:** `remote worldwide`, `anywhere in Europe`, `timezone UTC-5 to UTC+5`, `contractor / Deel / EOR`, немає згадки 401(k).
